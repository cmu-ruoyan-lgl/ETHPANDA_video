批量对“已切分”的英文 SRT 进行优化：去除语气词与口头赘述，保持原意与 SRT 格式，并统一常见 Web3 专有名词写法（如 Web3、DeFi、NFT、PoS/PoW、ZK Rollups 等）。

### 特点
- 保留编号与时间轴行，绝不改动时间戳；仅处理文本行。
- 去除常见口头语与不流畅部分（如 um/uh/you know/I mean/…），不改变原意。
- 统一 Web3 术语大小写与写法（case-insensitive），避免不一致。
- 保留原有换行与块结构，不会改变字幕格式。

### 一键处理“subtitles/”下所有小字幕

```bash
cd "/Users/ruoyan/Desktop/WorkSpace/ETHPANDA_video"
python3 ./scripts/optimize_english_srt.py --input "./subtitles" --output-dir "./subtitles_en_optimized"
```

处理结果会输出到 `subtitles_en_optimized/` 下，与原文件同名。

### 仅处理单个文件（示例）

```bash
cd "/Users/ruoyan/Desktop/WorkSpace/ETHPANDA_video"

```

### 说明与建议
- 该优化仅对文本行做“轻度清洗”，不会改动时间戳或编号，且尽量不破坏句义。
- Web3 术语采用常见写法（如 Web3/DeFi/NFT/DAO/EVM/PoS/PoW/Layer 2/ZK Rollups/TVL 等）。
- 若需扩展术语表，可在脚本 `scripts/optimize_english_srt.py` 中追加映射规则。
- 后续若需要中英对照，请结合 `docs/WEB3专有名词翻译.md` 进行术语一致性核对。
