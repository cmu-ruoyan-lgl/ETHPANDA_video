将下载后的 SRT 按“字幕块”安全切分为多个文件，输出到 `subtitles/`，并按顺序命名。

### 规则
- 仅在“字幕块”之间切分（块 = 编号 + 时间戳行 + 若干文本行 + 空行）；块内绝不拆分，确保时间戳与句子不被打断。
- 每个输出文件约 600 行（包含编号、时间戳、文本与空行）。若某个块本身行数较多，会单独占一份。
- 保留原文件内容与格式，不改动编号与时间戳。
- 输出目录：`subtitles/`
- 命名：`<原文件名去扩展>.part01.srt`、`part02.srt`、…

### 快速使用（切分最新的 SRT）

```bash
cd "/Users/ruoyan/Desktop/WorkSpace/ETHPANDA_video"
SRT_PATH=$(ls -1t "./video"/*.srt | head -n 1)
python3 ./scripts/split_srt.py --input "$SRT_PATH" --output-dir "./subtitles" --max-lines 600
```

### 指定文件切分（示例）

```bash
cd "/Users/ruoyan/Desktop/WorkSpace/ETHPANDA_video"
python3 ./scripts/split_srt.py \
  --input "./video/20251117_googlevideo_特朗普：好羡慕习主席，下属毕恭毕敬.en.srt" \
  --output-dir "./subtitles" \
  --max-lines 600
```

说明
- 脚本会自动创建 `subtitles/`（如不存在）。
- 可调整 `--max-lines` 以改变每份的“约行数”上限，但始终按块切分、不会破坏格式。
