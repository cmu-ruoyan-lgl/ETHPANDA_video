下载指定链接的视频到本仓库 `video` 目录，并自动命名（直链脚本）。

### 方式 B：在 Cursor 中一键下载（支持传参）

用法
- 在聊天框直接输入并发送：`/1.下载视频 <直链URL>`

示例

```bash
/1.下载视频 https://r5---sn-xxxx.googlevideo.com/videoplayback?... 
```

它会自动完成
- 切换到仓库目录：`/Users/ruoyan/Desktop/WorkSpace/ETHPANDA_video`
- 赋予脚本可执行权限：`chmod +x scripts/download_direct.sh`
- 以参数形式调用脚本：`URL="<直链>" ./scripts/download_direct.sh`

效果
- 文件保存至 `video/`，并自动命名为 `YYYYMMDD_googlevideo_<title>.mp4`
- 遇到临时失败会自动重试；如安装了 `aria2c` 会自动加速（否则回退 `curl`）

注意
- 需提供可直下的真实直链（如 `googlevideo` 直链）
- 首次使用若无可执行权限，将在执行过程中自动处理

### 方式 A：直链下载脚本（刚刚使用的方法｜自动重试）

用途
- 已拿到可直下的真实文件链接（如 `googlevideo` 直链）时，最快速、最稳定。

快速使用

```bash
cd "/Users/ruoyan/Desktop/WorkSpace/ETHPANDA_video"
chmod +x scripts/download_direct.sh
URL="<在这里粘贴直链>" ./scripts/download_direct.sh
```

说明
- 自动创建输出目录：保存到 `video/`
- 自动命名：`YYYYMMDD_googlevideo_<title>.mp4`
- 自动重试：直到下载达到直链 `clen`（或文件非空）
- 加速：若已安装 `aria2c` 将优先使用，否则回退 `curl`
- 成功后自动在 Finder 中高亮文件位置
- 如脚本内已嵌入直链，可直接执行：

```bash
./scripts/download_direct.sh
```

可选：将已有 SRT 字幕重命名为与最新视频同名，方便播放器自动加载

```bash
VIDEO_DIR="/Users/ruoyan/Desktop/WorkSpace/ETHPANDA_video/video"
MP4_PATH=$(ls -1t "$VIDEO_DIR"/*.mp4 | head -n 1)
mv "/path/to/your.srt" "${MP4_PATH%.mp4}.en.srt"
```
