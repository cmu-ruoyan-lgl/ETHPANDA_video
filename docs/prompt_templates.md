## LLM 提示词模板（可直接在 Cursor / Kimi / OpenAI 使用）

> 变量请按 `${变量名}` 搜索替换；如无相关信息可删除该行。

### 1. 英文字幕预处理（AI 辅助）
```
你是资深字幕编辑，负责优化英文讲稿。
输入是一段来自 Web3 会议的字幕文本（含基础标点）。
目标：
1. 删除或弱化无意义的语气词（uh, um, you know）。
2. 修正明显的 ASR 拼写/语法错误，保持技术术语原样。
3. 控制句长：每条字幕最多 2 行、单行 <= 42 字符。
4. 保留原意，不新增事实。
输出：
- 使用 Markdown 表格，字段：`原句`、`优化后句子`、`备注`（若无备注写`-`）。
- 不要输出与任务无关的文字。

字幕片段：
${english_snippet}
```

### 2. 术语审查与补充
```
你是 Web3 术语专家。请根据字幕内容，识别可能需要固定译法的术语。
输入：字幕片段 + 现有术语表（格式 `"英文" -> "中文"`）。
任务：
1. 标记未出现在术语表中的专有名词，并给出推荐中文译法。
2. 如译法已有，请确认是否一致；不一致需给出建议。
输出：
- 使用 Markdown 表格：`英文术语` | `建议中文` | `备注（沿用/新增/确认冲突）`

字幕：
${english_snippet}

术语表摘录：
${glossary_excerpt}
```

### 3. 英译中（逐条）
```
角色：你是熟悉区块链的中英翻译。
要求：
1. 逐条翻译字幕，每条输出两行：第一行中文，第二行英文原文。
2. 保留形如“⟦G数字⟧”的占位符不变。
3. 专有名词遵循术语表：${glossary_rules}
4. 语气自然，适合中文视频字幕。
输入：
${indexed_english_block}

输出格式（示例）：
01
<中文翻译>
<原文英文>
```

### 4. 中英双语对位校对
```
你是字幕 QA。需要检查双语 SRT 中的每一条字幕是否满足：
- 中文与英文表达同义，且无缺漏。
- 数字、单位、专有名词一致。
- 中文行在前，英文行在后。
- 若发现问题，指出编号并给出修正建议。
输入：
${bilingual_excerpt}

输出示例：
- `#23`：中文遗漏 “Layer 2”，建议补充。
- `#24`：中文行在后，请调整顺序。
若无问题，说明“全部通过”。
```

### 5. QA 报告生成
```
请根据处理日志生成 QA 总结。
输入包含：读速统计、术语校验结果、人工备注。
输出：
- 列出阻断级问题（Must Fix）、警告（Warn）、建议（Info）。
- 给出下一步处理建议。

处理日志：
${qa_log}
```

### 6. 失败重跑提示（用于模型微调）
```
上轮字幕翻译存在如下问题：
${issue_list}

请在新的翻译中：
1. 严格遵守术语表；
2. 逐条输出两行（中文+英文）；
3. 不要在输出中添加额外解释。
待翻译内容：
${english_snippet}
```
