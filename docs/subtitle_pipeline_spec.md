## 视频字幕处理与优化脚本 需求规格说明（V1）

### 背景与目标
- **目标**：对视频字幕进行全流程优化，产出可读性更强、时间戳精准、专有名词一致、且中英双语对位的字幕文件。
- **核心价值**：提升英文字幕可读性与专业性；生成高质量中文翻译；输出可直接用于发布或二次编辑的双语字幕。

### 范围
- **在范围**：
  - 字幕获取与预处理（含 AI 初稿）
  - 语气词清理与规则化
  - 英文拼写/语法/可读性优化
  - 长字幕切分与时间戳精修（Pro 时间戳）
  - 专有名词识别/保护/术语统一
  - 英译中（可控语气/专业度）
  - 中英双语对位与导出
  - 一轮整体改写与复优化（迭代）
- **不在范围（V1）**：
  - 字幕样式高级渲染（ASS 动效）
  - 多语种（除中英外）
  - 自动内容审查与敏感词策略

### 术语
- **AI 字幕**：由 ASR/LLM 生成的初稿字幕（文本+时间戳）。
- **语气词**：如「嗯/啊/呃」「um/uh/er」等不承载语义的信息噪声。
- **Pro 时间戳**：时间戳精修；指切分后对文本与区间进行精准对齐/插值/微调。
- **双语对位**：同一条字幕中，英文与中文一一对应且共用或严格对齐时间轴。

### 总体流程
1) 输入拉取 → 2) AI 初稿/导入 → 3) 预处理（清洗/规整） → 4) 语气词处理  
→ 5) 英文可读性/语法/拼写优化 → 6) 过长切分 → 7) Pro 时间戳精修  
→ 8) 专有名词识别与保护 → 9) 英译中 → 10) 中英双语对位  
→ 11) 一轮整体改写 → 12) 复优化（第二轮） → 13) 导出与校验

### 输入与输出
- **输入**：
  - 视频文件：mp4/mov（可选）
  - 原始字幕：srt/vtt（可选；若空则走 ASR 生成）
  - 术语表/词典：csv/yaml（专有名词、固定译法）
  - 语言参数：源语种（默认英语）、目标语种（中文）
- **输出**：
  - `xxx.en.srt`：英文优化版（时间戳精修）
  - `xxx.zh.srt`：中文译制版（与英文对齐）
  - `xxx.bilingual.srt`：双语同条（第一行英文，第二行中文）
  - 日志与质检报告（可读性、术语一致性、时间戳漂移等）

### 详细功能需求

#### 1. 字幕获取（拉字幕）
- 自动检测是否存在可用字幕；无则走 ASR（如 Whisper）。
- 兼容 `srt/vtt` 读取；保留时间戳与顺序。

#### 2. AI 初稿预处理
- 统一空白/标点/大小写（英文句首大写、专名规则化）。
- 正规化常见噪声符号与连字符、破折号。
- 合并/分裂明显错分段（基于时间间隔和标点闭合）。

#### 3. 语气词处理（中英）
- 规则：
  - 句中孤立语气词默认移除。
  - 若承载语气/强调（如访谈卡顿）可降权为逗号停顿或保留一次。
- 可配置白名单与强制保留上下文模式（如喜剧/直播需保留风格）。

#### 4. 英文可读性与词汇优化
- 拼写/语法检查（专名不被错误纠正）。
- 简化冗长句式、断句增强可读性（不改变原意）。
- 限制每行最大字符数与每条最大行数（如最多 2 行）。
- 确保观众能“看的懂、来得及读”；遵循读速阈值。

#### 5. 过大字幕切分
- 触发条件：超出字符/时长/读速限制。
- 切分策略：
  - 优先按标点和语义边界。
  - 不在专名、数字、URL 中间断开。
  - 必要时按时长与读速进行均匀切分并加过渡词优化。
- 切分后保序、保义、无截断歧义。

#### 6. Pro 时间戳（时间戳精修）
- 切分后对新片段时间戳按文本长度比例插值。
- 启用微对齐：避免重叠/空洞，保留最小间隔（如 ≥80ms）。
- 可选强对齐：基于对齐器进行音频强制对齐（提高精度）。

#### 7. 专有名词识别与保护
- NER + 术语表：
  - 识别人名、机构、产品、链名、协议名等。
  - 英文优化阶段保护大小写与拼写。
  - 翻译阶段使用固定译法（可配置优先级）。
- 术语一致性检查与报告。

#### 8. 英译中（中文翻译）
- 翻译保真+可读：专业名词不直译，遵循术语表。
- 标点与断句符合中文习惯；口语化与书面化可配置。
- 数字、单位、货币、链上术语格式化。

#### 9. 中英双语对位
- 同条字幕内中英一一对应；若时长变动则统一采用英文时间轴。
- 处理英文与中文长度不对称：必要时中文断句但不改变时间轴数量。
- 导出三种版本（英/中/双语），确保行数与时间戳关系稳定。

#### 10. 一轮改写与复优化
- 第一轮：全局风格一致化（人称、时态、口吻）、冗余合并、读速再校正。
- 第二轮（复优化）：术语二次核对、可读性阈值收紧、边角异常修正。

#### 11. 日志与质检
- 每阶段产出结构化日志（变更摘要、警告、失败原因）。
- 质检指标：读速、时间戳重叠率、术语一致率、拼写错误率。
- 导出最终 QA 报告。

### 质量指标与验收标准
- **时间戳漂移**：切分/精修后相对原音频漂移 ≤ 120ms（P95）。
- **读速**：平均 ≤ 17 CPS（characters per second），峰值 ≤ 20 CPS。
- **每行字符数**：建议 ≤ 42；每条 ≤ 2 行。
- **重叠/空洞**：无重叠；相邻条目间隙 ≥ 80ms。
- **术语一致性**：术语表覆盖项一致率 ≥ 98%。
- **拼写/语法**：显著错误率 0；轻微提示项 ≤ 1/千词。
- **译文可读性**：人工抽检通过率 ≥ 95%。

### 可配置项（示例）
- 语气词策略：remove/soften/keep、白名单、上下文阈值
- 读速阈值：avg/max CPS、最大时长、最小间隔
- 切分：标点优先/均匀切分、最大字符/行数
- 时间戳：插值方式、强制对齐开关、最小间隔
- 翻译：风格（口语/出版/技术）、敬语、中文标点
- 术语：词典优先级、未知术语报警级别
- 输出：英/中/双语启用、文件格式 srt/vtt

### 错误处理与边界
- 无音频或音频损坏：回退到文本级处理并标注低置信度。
- 字幕严重错位：触发强对齐或人工复核标记。
- 术语冲突：按优先级决策并在报告中列出。
- 超长视频：自动分块处理（带上下文重叠），结果再拼接。

### 性能与资源
- 支持批量；并发度可配。
- ASR/LLM 可选本地或远程；大模型超时/限流策略。
- 大文件分块阈值（如 30 分钟/300KB 字幕）。

### 命令行/服务接口草案

- 命令行

```bash
subtitle-opt \
  --in video.mp4 \
  --in-sub input.srt \
  --src-lang en \
  --tgt-lang zh \
  --glossary glossary.csv \
  --max-cps 17 \
  --max-line 42 \
  --max-lines-per-cue 2 \
  --min-gap-ms 80 \
  --pro-ts strict \
  --filler-policy soften \
  --out-dir ./out \
  --export en,zh,bilingual
```

- 返回文件
  - `out/xxx.en.srt`
  - `out/xxx.zh.srt`
  - `out/xxx.bilingual.srt`
  - `out/xxx.qc.json`（质检指标）

### 目录结构建议
- `data/` 输入样例与术语表  
- `out/` 输出与报告  
- `configs/` 默认配置与风格预设  
- `logs/` 运行日志与质检记录

### 待确认项
- 是否必须保留少量语气词以体现口语风格？按场景区分策略？
- 英文优化强度：更通俗还是更学术？
- 中文风格：口语/媒体/技术文档三档的默认选择？
- 双语导出：一条两行 vs 两条并列（发布平台兼容性偏好）？
- 时间戳精修是否默认开启强制对齐（增加计算成本）？
- 验收阈值（CPS、术语一致率）的最终数值是否需要按频道微调？

### 里程碑
- M1：流程打通（AI 初稿→预处理→切分→导出），基础 QA
- M2：Pro 时间戳与术语一致性，双语对位稳定
- M3：一轮改写+复优化与全面质检报告
- M4：配置模板与批量任务、性能优化
